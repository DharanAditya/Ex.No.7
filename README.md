## AIM

To develop a prompt-based application using ChatGPT that helps organize daily activities and demonstrates the progression from simple prompts to advanced prompts for practical problem-solving.

---

## AI TOOLS REQUIRED

* ChatGPT
* Large Language Model (LLM)

---

## APPLICATION

### Personal Productivity Assistant

A **Personal Productivity Assistant** is designed to help users manage daily tasks, reminders, schedules and general queries through natural-language interaction.

### Main Features

* Daily task management
* Reminder and schedule suggestions
* Task prioritization
* Daily task summaries
* Wellness suggestions
* General question answering
* Adaptation to user preferences

---

## PROMPT USED

```text
Act as a personal productivity assistant.

Help me manage my daily tasks, organize them based on priority
and deadlines, suggest suitable reminders, provide simple
wellness tips, and answer general queries.

Interact with me using natural language. Ask for missing
information when necessary and adapt your suggestions based
on my preferences and previous interactions.

Provide responses in a simple, clear and organized format.
```

---

## PROMPT PROGRESSION

### 1. Basic Prompt

```text
Help me manage my daily tasks.
```

**Output:**

```text
Sure. Please provide your tasks along with their deadlines
and priorities.
```

### 2. Improved Prompt

```text
Help me organize my daily tasks based on priority and deadline.
```

**Output:**

```text
High Priority:
- Complete project report – Today

Medium Priority:
- Study for test – Tomorrow

Low Priority:
- Organize notes – This week
```

### 3. Advanced Prompt

```text
Act as my personal productivity assistant. Organize my tasks
according to priority and deadline, suggest suitable schedules,
identify conflicting activities, provide a daily summary and
suggest a short wellness activity. Keep the response concise
and easy to follow.
```

**Output:**

```text
Today's Priority:
1. Complete project report
2. Attend online class
3. Review study notes

Suggested Schedule:
10:00 AM – Online class
2:00 PM – Project work
6:00 PM – Review notes

Wellness Tip:
Take a 10-minute break after every 60–90 minutes of work.
```

---

## PROCEDURE

1. Identify the requirements of a personal productivity assistant.
2. Create a basic prompt for managing daily tasks.
3. Improve the prompt by adding priority and deadline handling.
4. Develop an advanced prompt with scheduling and wellness features.
5. Enter different user requests into ChatGPT.
6. Observe and compare the responses produced by different prompts.
7. Refine the prompts based on the output.
8. Document the final prompt and generated responses.

## OBSERVATIONS

* Simple prompts provide general responses.
* Detailed prompts provide more relevant results.
* Adding roles and constraints improves response quality.
* Natural-language interaction makes the application easy to use.
* Prompt refinement helps customize the assistant according to user requirements.

---

## RESULT

A prototype **Personal Productivity Assistant** was successfully developed using ChatGPT. Different levels of prompts were created and tested to manage tasks, organize schedules, provide wellness suggestions and generate personalized responses.

## CONCLUSION

The experiment demonstrated how prompt engineering can be used to develop practical applications with large language models. By progressively refining prompts, the productivity assistant was able to provide more structured, relevant and personalized responses for everyday task management.
